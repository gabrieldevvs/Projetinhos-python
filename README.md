# Gerencriador de Estoque em Python

Projeto desenvolvido para colocar em prática os conhecimentos que venho adquirindo em Python e banco de dados.

O sistema permite realizar o cadastro de produtos, consultar informações, atualizar o estoque, excluir produtos e verificar se um item está dentro da validade. Os dados são armazenados em um banco SQLite.

## Funcionalidades

- Cadastro de produtos
- Consulta de produtos
- Atualização de estoque
- Exclusão de produtos
- Verificação de validade dos produtos

## Tecnologias utilizadas

- Python
- SQLite
- PyODBC
- SQL

## Aprendizados

Durante o desenvolvimento deste projeto pratiquei:

- criação e manipulação de banco de dados;
- comandos SQL (INSERT, SELECT, UPDATE e DELETE);
- validação de entradas do usuário;
- uso de funções;
- manipulação de datas para verificar a validade dos produtos.

Este projeto faz parte da minha evolução nos estudos de Python. Conforme eu for adquirindo novos conhecimentos, pretendo melhorar o código e adicionar novas funcionalidades.
